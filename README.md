# Autofix-DB

Propósito

Diseñar y crear una base de datos para una aplicación de administración de talleres mecánicos. El proyecto busca organizar la información de clientes, vehículos, empleados, servicios y reparaciones, facilitando el seguimiento de los trabajos realizados en el taller.

Estructura de carpetas propuesta

documentacion/: requisitos, descripción del proyecto y documentos de apoyo.

diagramas/: diagrama entidad-relación y diseño de la base de datos.

scripts/: archivos SQL para crear la base de datos, tablas y relaciones.

datos/: registros de ejemplo para realizar pruebas.

consultas/: consultas SQL para obtener y analizar información.

pruebas/: pruebas para verificar el funcionamiento y la integridad de los datos.

El archivo README.md estará en la raíz del repositorio y contendrá la información general del proyecto.



Cómo colaborar

Clonar el repositorio para trabajar en una copia local.

Actualizar la rama principal antes de comenzar una tarea.

Crear una rama propia con un nombre relacionado con el trabajo, por ejemplo: feature/tabla-clientes.

Realizar los cambios y guardar los archivos en la carpeta correspondiente.

Probar los scripts SQL antes de compartirlos. Utilizar datos ficticios para las pruebas.

Crear commits con mensajes claros, por ejemplo: Agrega tabla de clientes.

Subir la rama y abrir un Pull Request, explicando los cambios realizados.

Solicitar la revisión de otro integrante antes de integrar los cambios a la rama principal.
